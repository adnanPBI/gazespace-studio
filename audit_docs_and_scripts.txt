# GazeSpace 0.2 — Integration contract

**18 November 2026.** The Python engine, capture/runtime components and local telemetry service can be integrated into an existing Windows application. The client's original repository was not supplied, so the deliverable provides working interfaces and examples rather than claiming an already completed proprietary-code integration.

## 1. Choose one integration boundary

| Boundary | Use when | Responsibility |
|---|---|---|
| `GazeEngine.process` | Your application already owns a BGR camera stream | Host controls frame acquisition, timestamps, worker thread and UI updates |
| `GazeEngine.process_frame` | Frames also contain aligned depth and source metadata | Host preserves calibrated depth alignment and metadata |
| `TrackingRuntime` | GazeSpace should own acquisition and inference workers | GUI polls snapshots or receives an explicit result callback |
| Local HTTP/WebSocket | Existing code is a separate process/language | Consumer authenticates, checks freshness and clears invalid estimates |

Do not open the same camera simultaneously through an existing acquisition loop and a second GazeSpace source. Reuse the current frames or move ownership deliberately.

## 2. Frame and timestamp contract

`process(image_bgr, timestamp_s)` expects an unsigned 8-bit BGR array of shape `(height,width,3)`. The array must match the intrinsic calibration's exact resolution. Use `capture.to_bgr(raw, ir_bit_depth=12)` for a declared unpacked Mono12 source; packed industrial formats should be decoded through the vendor adapter.

Use a strictly increasing source timestamp for filtering. A host-receive timestamp is useful for processing, but it is not the sensor's exposure time. Preserve synchronized hardware timestamps separately when available. Video sources preserve presentation-time behavior instead of deriving motion timing from decoder throughput.

`Frame` also supports `metadata`, `received_monotonic_s`, `hardware_timestamp_s`, and optional `depth_m`. An aligned depth image uses meters and the color image's pixel grid.

**Host arrival times and freshness deadlines use `gazespace.clock.host_now_s()`, backed by `time.perf_counter()`.** Its reported domain is `gazespace.perf_counter`; the epoch is unspecified. Use this same function in custom acquisition callbacks and UI freshness checks. On Windows Python 3.11/3.12, `time.monotonic()` has a different, coarser clock implementation; mixing its absolute values with `perf_counter()` breaks age checks and can duplicate rapid camera timestamps. Python documents the Windows implementation change in its [3.13 time release notes](https://docs.python.org/3.13/whatsnew/3.13.html#time). The engine does not fabricate increments to make source timestamps appear distinct.

For a custom live source, timestamp and copy the owned buffer at acquisition:

```python
from gazespace.clock import HOST_CLOCK_DOMAIN, host_now_s
from gazespace.capture import to_bgr
from gazespace.types import Frame

raw = existing_camera.read()
received = host_now_s()
frame = Frame(
    image=to_bgr(raw),
    timestamp_s=received,
    received_monotonic_s=received,
    metadata={"host_clock_domain": HOST_CLOCK_DOMAIN},
)
```

For a video or a device with its own source timeline, keep `timestamp_s` in that timeline and set `received_monotonic_s` separately with `host_now_s()`. Never compare video PTS, a hardware timestamp, UTC, or a remote process's source timestamp with the host freshness clock. `TrackingRuntime` rejects nonfinite, future, or explicitly mismatched receive clocks and clears active gaze when a frame expires. Source clock resets still require restarting/resetting the tracking sequence. Existing recordings retain their relative `session_time_s` replay timeline; no recorded timestamps are rewritten by this change.

One engine is stateful. Construct and use it on the same processing thread, process frames sequentially, and close it after that thread has stopped. MediaPipe state and One Euro filters must not be called concurrently. Pass UI updates through the GUI framework's thread-safe mechanism.

## 3. Profile compatibility is part of integration

Schema-2 profiles contain measured geometry, fitted models, feature versions, validation evidence and context. Model metadata can bind:

- Camera/source ID, backend and selected subject ID.
- Exposure/gain configuration and declared monochrome bit depth.
- Tracking mode, pupil polarity, selected ROI, feature method/version and face-model identity.
- Actual frame resolution and intrinsic-calibration fingerprint.
- Eye-origin method, such as generic face PnP or aligned-depth pupil midpoint.
- Display identity and calibrated pixel dimensions for screen mapping.

Supply the **actual current configuration**, not a copy of the saved model's expected values. The engine checks provided fields and frame-derived context. Low-level/headless callers may omit some external display/source information; omission is not a verified match. Hosts requiring strict acceptance should call `model.context_mismatches(actual_context, require_present=True)` after assembling every applicable field and reject unresolved differences before consuming output.

Version-1 learned models are invalidated when loaded because head and eye-feature conventions changed. Do not attempt to repair old model coefficients by renaming their version fields.

### In-process example

```python
from gazespace.engine import GazeEngine

# Obtain these values from the host's current settings/device/display.
current_context = {
    "camera_id": "0",
    "backend": "dshow",
    "subject_id": "operator-1",
    "exposure_native": None,
    "exposure_us": None,
    "gain": None,
    "ir_bit_depth": 8,
    "monitor": actual_monitor_name,
    "screen_size": [actual_pixel_width, actual_pixel_height],
}

# Construct this inside your processing worker, not the GUI constructor.
engine = GazeEngine.from_profile(
    "profiles/operator-camera.json",
    mode="rgb",
    source_context=current_context,
)
try:
    for frame_bgr, captured_monotonic_s in existing_camera_frames():
        result = engine.process(frame_bgr, captured_monotonic_s)
        if result.screen_valid and result.gaze_screen_px is not None:
            publish_to_gui(result.as_dict())
        elif result.spatial_valid and result.surface_name is not None:
            publish_to_gui(result.as_dict())
        else:
            clear_host_gaze_selection(result.reason)
finally:
    engine.close()
```

The functions and display variables named `existing_*`, `actual_*` and `publish_*` are the integration points in the host application. Do not treat them as GazeSpace APIs.

## 4. Runtime-managed acquisition

```python
from gazespace.capture import create_source
from gazespace.engine import GazeEngine
from gazespace.runtime import TrackingRuntime

runtime = TrackingRuntime(
    source_factory=lambda: create_source(0, backend="dshow", width=1280, height=720, fps=30),
    engine_factory=lambda: GazeEngine.from_profile(
        "profiles/operator-camera.json", mode="rgb", source_context=current_context
    ),
    max_age_s=0.4,
    reconnect_attempts=5,
)
runtime.start()
```

The source is created in the acquisition worker; the engine is created in the inference worker. A bounded newest-frame mailbox drops obsolete pending frames instead of building an unbounded latency backlog. The UI can poll:

```python
snapshot = runtime.snapshot()           # local Frame/Observation/Result plus metrics
telemetry = runtime.telemetry()         # JSON-safe metadata representation
runtime.pause()
runtime.resume()
fully_stopped = runtime.stop(timeout=3)
```

When `stop()` returns `False`, a driver/OS call is still active. Output is invalidated, and the runtime must not be replaced by another instance opening the same device until shutdown completes. The application does not attempt unsafe cross-thread destruction of a camera currently in use.

`on_result(frame, observation, result)` can record or forward each processed frame exactly once. Keep the callback short; it executes in the processing worker. Callback errors are exposed in runtime metrics. Metadata recording avoids raw images unless separately selected.

## 5. Result semantics

Important `GazeResult` fields:

| Field | Meaning |
|---|---|
| `valid` | At least one usable calibrated estimate exists for this observation |
| `screen_valid`, `spatial_valid` | Validity of each output path separately |
| `reason`, `warnings` | Explicit tracking, calibration, envelope or geometry conditions |
| `quality` | Heuristic tracking quality, not a calibrated probability of accuracy |
| `gaze_screen_px` | Filtered local coordinates on the calibrated display |
| `raw_gaze_screen_px` | Unfiltered model prediction when available |
| `gaze_screen_normalized` | Screen XY normalized to `[0,1]` |
| `ray_origin_world_m` | Eye-origin estimate in world meters |
| `ray_direction_world` | Unit gaze direction in the same world frame |
| `surface_name`, `surface_xy_m` | Nearest bounded hit and its local metric UV |
| `surface_xy_px` | Optional surface UV mapped to declared display pixels |
| `eye_origin_source` | Explicit source of metric eye-position geometry |
| `processing_ms` | Processing duration for this frame |
| `capture_timestamp_s` | Source timestamp used by the temporal pipeline |
| `model_fingerprint`, `tracking_context` | Provenance/compatibility data |

A spatial ray may be valid without hitting any configured surface. `spatial_ray_only_no_surface_hit` must not activate a surface selection. Clear prior selections when validity is lost; do not keep acting on the last successful point.

## 6. Coordinate conventions

- **Camera:** X right, Y down, Z forward; distances in meters.
- **World:** the measured reference-board frame. Extrinsics satisfy `point_camera = R_world_to_camera @ point_world + t_world_to_camera_m`.
- **Head:** the corrected camera-facing generic template has a neutral frontal orientation near zero rather than requiring a 180-degree pitch offset. Its anthropometric scale remains an approximation.
- **Screen:** top-left origin, X right, Y down; normalized 1 maps to `width−1` or `height−1`. Coordinates are local to the calibrated monitor, not automatically global Windows virtual-desktop coordinates.
- **Surface:** top-left metric UV relative to orthogonal U/V axes. The world-space origin, dimensions and optional pixel extent must be physically measured.

For Windows global cursor coordinates, the host would need to apply the actual monitor origin/DPI convention. GazeSpace does not move the system cursor or trigger clicks by default.

## 7. Local REST and WebSocket API

The desktop generates a fresh bearer token when its API starts and shares the running runtime. Bind address is `127.0.0.1`; choose the port in **Integration API**.

The CLI can launch its own service:

```powershell
$token = python -c "import secrets; print(secrets.token_urlsafe(32))"
python -m gazespace api --backend dshow --source 0 --mode rgb --profile profiles\operator.json --subject-id operator-1 --token $token --port 8765
```

For CLI operation, use a compatible CLI profile or supply an embedding context that covers the intended display/controls. `--token` is optional at the low-level CLI; use it when local consumers require authenticated access.

| Endpoint | Response |
|---|---|
| `GET /health` | Runtime state, running/error status |
| `GET /v1/gaze` | State, latest estimate, metrics and camera report |
| `GET /v1/metrics` | Runtime/engine metrics |
| `WS /v1/stream` | Periodic JSON telemetry updates |

Every HTTP request must use a loopback Host header. Browser origins must be localhost/loopback; external origins are rejected. Native clients normally omit the Origin header. The API does not provide an internet/LAN deployment mode.

Python client:

```python
import httpx
response = httpx.get(
    "http://127.0.0.1:8765/v1/gaze",
    headers={"Authorization": f"Bearer {token}"},
    timeout=2,
)
response.raise_for_status()
status = response.json()
latest = status.get("latest")
if status.get("state") == "running" and latest and latest.get("screen_valid"):
    consume_screen_point(latest["gaze_screen_px"])
else:
    clear_gaze()
```

Browser WebSocket from a permitted local origin:

```javascript
const socket = new WebSocket("ws://127.0.0.1:8765/v1/stream", [
  "gazespace", "bearer." + token
]);
socket.onmessage = event => {
  const status = JSON.parse(event.data);
  const gaze = status.latest;
  if (status.state === "running" && gaze?.screen_valid) {
    renderGaze(gaze.gaze_screen_px);
  } else {
    clearGaze();
  }
};
```

Stream updates may repeat the same capture observation; use the capture timestamp if you need exactly-once frame processing. No endpoint exposes raw image arrays, facial landmark arrays or model feature vectors. Output still contains sensitive behavioral coordinates and should be handled accordingly.

## 8. Depth and stereo integration

`RealSenseSource` produces color-aligned depth and its intrinsic metadata. `GazeEngine.process_frame` can use supported aligned depth to estimate a binocular visible-eye midpoint. Missing/invalid patches and unsupported distortion models are rejected. The origin is explicitly labeled `aligned_depth_pupil_midpoint`, which is not an optical eyeball center.

For custom depth adapters, preserve:

```python
frame.depth_m                         # HxW metric depth aligned to BGR color
frame.metadata["depth_aligned_to"]   # "color"
frame.metadata["depth_intrinsics"]   # measured/factory CameraIntrinsics.to_dict()
frame.metadata["depth_deprojection_supported"]  # truthful compatibility flag
```

`FrameSynchronizer(max_skew_s=.008, max_queue=6)` pairs left/right frames with bounded queues. Hardware timestamp comparison is allowed only when the adapter explicitly declares synchronized clocks. Host-receive pairing cannot prove simultaneous exposure.

`triangulate_points_checked(left_xy, right_xy, left_intr, right_intr, R, T)` reconstructs matched image points and reports validity, reprojection error and convergence angle. Supply corresponding unduplicated landmarks from both cameras; the utility does not solve eye-feature correspondence automatically. A metric pupil-surface point still requires gaze-direction calibration.

CLI triangulation input:

```json
{"left_px": [[320.0, 240.0]], "right_px": [[300.0, 240.0]]}
```

```powershell
python -m gazespace triangulate --left-profile profiles\left.json --right-profile profiles\right.json --rig profiles\stereo.json --observations matched_points.json --output reconstructed_points.json
```

## 9. Calibration and session extensions

`TargetCollector` is independent of GUI and camera ownership. It returns deep-copied settled observations, progress and explicit rejection reasons. Complete screen samples use normalized targets; spatial samples use measured world coordinates and current eye origin. New models should be fitted with `context=tracker.context(actual_image_size)` augmented by actual source/user/display settings and a distinct session ID.

`SessionRecorder`, `SessionReplay`, `analyze_session` and `export_report` can be used without the desktop. A recorder adds a monotonic session timeline separate from the original source timestamp, enabling replay after reconnects. Its default clock is `host_now_s()` and the saved timeline remains elapsed seconds from recording start. A custom injected recording clock remains supported; new manifests describe its clock provenance without changing the session schema or old-file replay. Metadata is validated before writing. Camera video requires explicit `record_video=True`.

Reports distinguish screen pixel error from dispersion, processing time from capture-to-display latency, and simulated evidence from physical measurements. Preserve those distinctions when forwarding data to clients.

Bright/dark clipping and mean luminance are scalar observations, not a measurement of pupil-detection accuracy.

Monitor geometry and DPI describe the active Qt process and session. Remote/virtual displays and monitor-reported physical dimensions are not independent measurements of a physical workspace. Use the application's actual target dialogs on the intended display and verify their physical placement separately.

## Bounded acquisition and cleanup

The camera is created, read and closed by one worker process. The supervisor allows the requested acquisition duration plus 20 seconds for startup and 10 seconds for shutdown. If a driver remains blocked, the supervisor terminates only its own worker and writes a timeout receipt with `clean_shutdown=false`. The outer Windows collector also bounds each launched process and retains logs/checkpoints. It never labels forced termination as successful cleanup.

Acquisition duration is restricted to 1–300 seconds per invocation. Run separate, clearly named receipts for repeated trials or different conditions. The collector does not automate USB unplugging, sleep/wake, changes to IR emitters, focus, camera placement or a person's fixation targets.

## Direct helper commands

Source environment:

```powershell
.venv\Scripts\python.exe scripts\environment_acceptance.py --output environment.json --sdk-inventory all
.venv\Scripts\python.exe scripts\camera_acceptance.py --backend dshow --source 0 --seconds 30 --output camera.json
```

Frozen CLI:

```powershell
GazeSpaceCLI.exe environment-probe --output environment.json --sdk-inventory all
GazeSpaceCLI.exe camera-soak --backend dshow --source 0 --seconds 30 --output camera.json
```

These helper commands are dispatched by the packaged CLI entrypoint. They are not subcommands of `python -m gazespace` in this version. Normal application CLI commands continue through the regular application parser.

The Windows build's Basler option additionally runs a short camera soak through the frozen CLI against the **enumerated SDK emulator**. That validates packaged SDK loading, acquisition and cleanup while retaining nonphysical provenance.

The depth build option verifies RealSense SDK import/context creation and device enumeration in both source and frozen runtimes. A zero-device result is valid SDK-discovery evidence and is not a physical capture test. The supplied Windows CI build enables both `-Basler` and `-Depth`; builds without a particular switch explicitly exclude that optional SDK.

Human gaze accuracy, drift under actual use, measured 3D targets, IR optics and existing-client integration still require their real inputs and observations. Continue with [WINDOWS_HARDWARE_ACCEPTANCE.md](WINDOWS_HARDWARE_ACCEPTANCE.md) for those measurements.

## Client inputs needed for final acceptance

1. The existing Windows project or a concrete integration interface, dependency lock and deployment method.
2. Exact camera model/serial/firmware, lens, resolution, pixel format, shutter/trigger mode and vendor SDK/driver versions.
3. IR emitter wavelength, operating distance, illumination layout and appropriate eye-safety evidence from the hardware supplier.

## Acceptance sequence

### A. Environment and baseline

Record Windows edition/build, CPU/GPU, USB controller, device drivers, camera serial, lens/focus, exposure/gain and display settings. Run `doctor`, save diagnostics, and measure the current client's application before integrating changes.

Build and run the Windows distributions on the actual target. Test startup, shutdown, repeated open/close, camera exclusivity, permissions, sleep/wake and device unplug/replug. Do not forcefully release a camera from another thread while its driver call is blocked.

### B. Camera and optics

Capture at the required resolution/FPS for a sustained run. Record dropped frames, actual frame sizes, timestamps and control readbacks. Verify Mono/packed-format handling against the sensor documentation. Confirm the physical sensor's shutter mode; the application never derives global shutter from a camera being USB-connected.

Measure sharpness/pupil pixel diameter over the expected head distances. Test ambient light changes, eyewear reflections, partial eye occlusion, natural blinks and approved head motions. Image quality constraints may require different optics or a dedicated eye camera rather than a different regression model.

### C. Calibration geometry

Capture diverse training board views, preserving the final camera focus/resolution. Measure fresh held-out views with fixed intrinsics. Report both fitted and held-out reprojection errors and rejected views. Keep camera-world origin and board orientation explicit; verify known physical points after solving the transform.

For stereo, capture synchronized pairs and verify baseline/epipolar geometry using additional independent views. Measure inter-camera skew independently where exposure simultaneity matters. Host timestamps and SDK tick counters do not become synchronized simply because they exist.

### D. Gaze validation

Collect person-specific target data using the application. Test fresh targets/session data across the intended screen and workspace. Include different head poses and distances that represent actual use.

Record:

- Median, p95 and maximum screen pixel error; optionally convert to visual angle using measured viewing distance and display geometry.
- Angular spatial-ray error and physical surface miss measurements with explicit eye-origin assumptions.
- Valid/invalid frame fraction and rejection reasons.
- Stationary-fixation RMS jitter and per-axis deviation, separately from intended movement.
- Repeated-target drift before and after the agreed operating interval and movement conditions.
- Capture-to-consumer/display latency, using actual timestamp instrumentation; do not substitute only processing milliseconds.

A generic facial template estimates eye origin. Aligned depth estimates an eye surface. A true pupil-center/corneal-reflection model, calibrated illuminator geometry or independent eye-tracker reference may be required if the accuracy target exceeds the optical/model limits of this implementation.

### E. Existing-application integration and release

Verify the actual in-process or API integration against a known data contract. Reject stale/invalid output, prevent UI blocking, test stopped/faulted states, and validate coordinates against the application's monitor/world conventions. Review logs and optional recordings for data handling and retention.

Build the intended Windows artifacts, run their smoke tests, sign with the authorized publisher identity if required, verify signatures, and run the client acceptance tests against that exact build. Record executable hashes and configuration alongside the result.

Run directly with Python, or through ``GazeSpaceCLI camera-soak``. A separate

def utc_now() -> str:
    return datetime.now(timezone.utc).isoformat()


def json_value(value):
    if isinstance(value, dict):
        return {str(k): json_value(v) for k, v in value.items()}
    if isinstance(value, (list, tuple)):
        return [json_value(v) for v in value]
    if isinstance(value, float) and not math.isfinite(value):
        return None
    if hasattr(value, 'item'):
        return json_value(value.item())
    if value is None or isinstance(value, (str, int, float, bool)):
        return value
    return str(value)


def write_json(path: Path, report: dict) -> None:
    temporary = path.with_suffix(path.suffix + '.tmp')
    temporary.write_text(json.dumps(json_value(report), indent=2, allow_nan=False) + '\n', encoding='utf-8')
    os.replace(temporary, path)


def file_hash(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open('rb') as stream:
        for block in iter(lambda: stream.read(1024 * 1024), b''):
            digest.update(block)
    return digest.hexdigest()


def summarize(values: list[float]) -> dict:
    if not values:
        return {'count': 0, 'minimum': None, 'median': None, 'p95': None, 'maximum': None}
    import numpy as np
    data = np.asarray(values, dtype=float)
    data = data[np.isfinite(data)]
    if not len(data):
        return summarize([])
    return {'count': len(data), 'minimum': float(data.min()), 'median': float(np.median(data)),
            'p95': float(np.percentile(data, 95)), 'maximum': float(data.max())}


def wait_bounded(process: subprocess.Popen, timeout_s: float) -> tuple[int, bool]:
    """Only terminate the worker started by this acceptance command."""
    try:
        return process.wait(timeout=timeout_s), False
    except subprocess.TimeoutExpired:
        process.kill()
        return process.wait(timeout=10), True


def run_worker(config: dict, checkpoint: Path) -> int:

    import numpy as np
    from gazespace import __version__
    from gazespace.capture import create_source

    report = {
        'schema_version': 1, 'status': 'opening_camera', 'started_at_utc': utc_now(),
        'application_version': __version__, 'python': platform.python_version(),

        'executable_sha256': file_hash(Path(sys.executable)), 'configuration': config,

        'global_shutter_verified': False,
        'measurement_scope': 'Camera delivery and software read timing; no gaze model or fixation ground truth',

    read_times: list[float] = []
    ages: list[float] = []
    luminance: list[float] = []
    dark_clipping: list[float] = []
    bright_clipping: list[float] = []
    depth_coverage: list[float] = []
    shapes: Counter = Counter()
    invalid_frames = 0
    read_failures = 0
    timestamp_errors = 0
    host_clock_errors = 0
    sequence_discontinuities = 0
    previous_stamp = None
    previous_sequence = None
    actual_duration = 0.0
    acquisition_error = None
    close_error = None
    capture_started = None
    opened = host_now_s()
    last_checkpoint = opened

              'receive_to_script_ms', 'arrival_gap_ms', 'width', 'height',

        if not simulated and not capabilities.get('is_live', getattr(source, 'is_live', False)):
            raise ValueError('Recorded files cannot establish live camera acceptance')

            raise ValueError('Discovered device serial differs from the explicitly selected serial')

        write_json(checkpoint, report)
        capture_started = host_now_s()
        deadline = capture_started + config['seconds']
        with timing_path.open('w', encoding='utf-8', newline='') as stream:
            writer = csv.DictWriter(stream, fieldnames=fields)
            writer.writeheader()
            while host_now_s() < deadline:
                before = host_now_s()
                frame = source.read()
                arrived = host_now_s()
                if frame is None:
                    read_failures += 1
                    time.sleep(0.005)
                    continue
                if any(bool(frame.metadata.get(k)) for k in ('synthetic', 'simulated', 'sdk_emulator')):
                    report['simulated'] = True
                    if not config['allow_simulated']:
                        raise ValueError('Frame metadata identifies simulated capture')
                image = frame.image
                if not isinstance(image, np.ndarray) or image.dtype != np.uint8 or image.ndim != 3 or image.shape[2] != 3 or image.size == 0:
                    invalid_frames += 1
                    continue
                height, width = image.shape[:2]
                shapes[f'{width}x{height}'] += 1
                stamp = float(frame.timestamp_s)
                if not math.isfinite(stamp) or (previous_stamp is not None and stamp <= previous_stamp):

                previous_stamp = stamp

                    sequence_discontinuities += 1

                receive = frame.received_monotonic_s

                if not clock_valid:
                    host_clock_errors += 1
                age_ms = (arrived - receive) * 1000 if clock_valid else None
                if age_ms is not None:
                    ages.append(age_ms)
                read_ms = (arrived - before) * 1000
                read_times.append(read_ms)
                gap_ms = None if not frame_times else (arrived - frame_times[-1]) * 1000
                frame_times.append(arrived)
                stride = max(1, math.ceil(max(width, height) / 320))
                gray = cv2.cvtColor(image[::stride, ::stride], cv2.COLOR_BGR2GRAY)
                mean = float(gray.mean())
                dark = float(np.mean(gray <= 2))
                bright = float(np.mean(gray >= 253))
                luminance.append(mean)
                dark_clipping.append(dark)
                bright_clipping.append(bright)
                valid_depth = None
                if frame.depth_m is not None:
                    depth = np.asarray(frame.depth_m)
                    valid_depth = float(np.mean(np.isfinite(depth) & (depth > 0)))
                    depth_coverage.append(valid_depth)

                    write_json(checkpoint, report)
                if arrived - last_checkpoint >= 1.0:

                    write_json(checkpoint, report)
                    stream.flush()
                    last_checkpoint = arrived

        report['camera_after_capture'] = json_value(source.capabilities())
    except Exception as exc:

    finally:
        if capture_started is not None:
            actual_duration = host_now_s() - capture_started
        report.update(status='closing_camera', frames_received=len(frame_times), acquisition_error=acquisition_error)
        write_json(checkpoint, report)
        if source is not None:

                source.close()

    fps = (len(frame_times) - 1) / (frame_times[-1] - frame_times[0]) if len(frame_times) > 1 else 0.0
    controls = report.get('camera_after_capture', report.get('camera', {})).get('controls', {})
    unconfirmed = [name for name, value in controls.items()
                   if value.get('applied') is not True or value.get('readback_matches') is False]

        'at_least_two_frames': len(frame_times) >= 2,

    if config.get('maximum_gap_ms') is not None:
        checks['explicit_maximum_arrival_gap'] = bool(gaps) and max(gaps) <= config['maximum_gap_ms']
    if config['require_exact_size']:

        completed_at_utc=utc_now(), capture_duration_s=actual_duration,

        read_failures=read_failures, invalid_frames=invalid_frames, timestamp_errors=timestamp_errors,

            'Passing these checks establishes bounded capture behavior, not human gaze or pupil accuracy.',

function Invoke-BoundedProcess {
    param([string]$Name, [string]$Executable, [string[]]$Arguments, [int]$TimeoutSeconds)
    $Stdout = Join-Path $OutputDirectory ($Name + '.stdout.log')
    $Stderr = Join-Path $OutputDirectory ($Name + '.stderr.log')

        $Process = Start-Process -FilePath $Executable -ArgumentList $NativeArguments -WorkingDirectory $ProjectRoot -PassThru -RedirectStandardOutput $Stdout -RedirectStandardError $Stderr
        [void]$Process.Handle

            # Only this collector's newly created process tree is terminated.
            # Camera acquisition has its own inner watchdog and partial receipt.
            try {

            } catch { if (-not $Process.HasExited) { Stop-Process -Id $Process.Id -Force } }
            return @{status='timeout'; timed_out=$true; exit_code=$null; duration_s=$Watch.Elapsed.TotalSeconds; started_at_utc=$Started.ToString('o'); executable=$Executable; arguments=$Arguments}
        }
        $Process.Refresh()
        return @{status=$(if ($Process.ExitCode -eq 0) {'passed'} else {'failed'}); timed_out=$false; exit_code=$Process.ExitCode; duration_s=$Watch.Elapsed.TotalSeconds; started_at_utc=$Started.ToString('o'); executable=$Executable; arguments=$Arguments}

class EmulatorVerificationError(RuntimeError):
    def __init__(self, report):
        self.report = report
        failure = report['failure']
        super().__init__(f"{failure['phase']}: {failure['exception_type']}: {failure['message']}")


def _plain(value):
    """Preserve diagnostic values without allowing nonfinite JSON constants."""
    if isinstance(value, dict):
        return {str(key): _plain(item) for key, item in value.items()}
    if isinstance(value, (list, tuple)):
        return [_plain(item) for item in value]
    if isinstance(value, float) and not math.isfinite(value):
        return f'nonfinite:{value}'
    if value is None or isinstance(value, (str, int, float, bool)):
        return value
    if hasattr(value, 'item'):
        return _plain(value.item())
    return repr(value)


def _write_report(output, report):
    if output is None:
        return
    path = Path(output)
    path.parent.mkdir(parents=True, exist_ok=True)
    data = json.dumps(_plain(report), indent=2, allow_nan=False) + '\n'
    temporary = None
    try:
        with tempfile.NamedTemporaryFile(mode='w', encoding='utf-8', dir=path.parent,
                                         prefix='.pylon-evidence-', delete=False) as stream:
            temporary = Path(stream.name)
            stream.write(data)
            stream.flush()
            os.fsync(stream.fileno())
        os.replace(temporary, path)
    finally:
        if temporary is not None:
            temporary.unlink(missing_ok=True)


def _clock_info(name):
    value = time.get_clock_info(name)
    return {'implementation': value.implementation, 'resolution_s': value.resolution,
            'monotonic': value.monotonic, 'adjustable': value.adjustable}


def _frame_summary(frame, index):
    if frame is None:
        return {'index': index, 'present': False}
    image = getattr(frame, 'image', None)
    flags = getattr(image, 'flags', None)
    return _plain({'index': index, 'present': True,
        'sequence': getattr(frame, 'sequence', None), 'source': getattr(frame, 'source', None),
        'timestamp_s': getattr(frame, 'timestamp_s', None),
        'received_monotonic_s': getattr(frame, 'received_monotonic_s', None),
        'hardware_timestamp_s': getattr(frame, 'hardware_timestamp_s', None),
        'metadata': getattr(frame, 'metadata', None),
        'image_type': type(image).__name__, 'array_shape': getattr(image, 'shape', None),
        'array_dtype': str(getattr(image, 'dtype', None)),
        'array_strides': getattr(image, 'strides', None),
        'owns_data': bool(flags.owndata) if flags is not None else None,
        'c_contiguous': bool(flags.c_contiguous) if flags is not None else None,
        'array_base_type': type(getattr(image, 'base', None)).__name__})


def _check(condition, gate, detail):
    # These gates must also execute when Python is launched with -O.
    if not condition:
        raise AssertionError(f'{gate}: {detail}')

        Invoke-Checked -Executable $ResolvedCli -Arguments @('doctor')
        $BundledFaceImage = Join-Path (Split-Path -Parent $ResolvedCli) 'examples\reference_face_nasa.png'
        if (-not (Test-Path -LiteralPath $BundledFaceImage)) { throw 'The frozen CLI distribution is missing its attributed reference-face fixture' }
        $FaceReceiptPath = Join-Path $EvidenceDirectory 'windows_packaged_face_inference.json'
        if (Test-Path -LiteralPath $FaceReceiptPath) { Remove-Item -LiteralPath $FaceReceiptPath -Force }
        Invoke-Checked -Executable $ResolvedCli -Arguments @('face-smoke', '--image', $BundledFaceImage, '--output', $FaceReceiptPath)
        $FaceReceipt = Get-Content -LiteralPath $FaceReceiptPath -Raw | ConvertFrom-Json
        if ($FaceReceipt.status -ne 'passed' -or -not $FaceReceipt.frozen_executable -or -not $FaceReceipt.face_detected -or $FaceReceipt.landmark_count -ne 478 -or $FaceReceipt.iris_count -ne 2 -or -not $FaceReceipt.features_finite) {
            throw 'The frozen MediaPipe facial/iris model failed the real-reference-photo inference gate'
        }
        if ($FaceReceipt.image_sha256 -ne (Get-FileHash -LiteralPath $BundledFaceImage -Algorithm SHA256).Hash) {
            throw 'The frozen face-inference receipt does not identify the bundled reference image'
        }
        if ($FaceReceipt.hardware_validated -or $FaceReceipt.gaze_accuracy_validated -or $FaceReceipt.head_angle_accuracy_validated -or $FaceReceipt.human_gaze_accuracy_measured) {
            throw 'A reference-photo inference check must not claim human gaze, pose accuracy or hardware acceptance'
        }
        $PackagedFaceChecked = $true
        Invoke-Checked -Executable $ResolvedCli -Arguments @('simulate', '--output', (Join-Path $EvidenceDirectory 'windows_packaged_simulation'), '--seconds', '2', '--record-video')
        $EnvironmentReceiptPath = Join-Path $EvidenceDirectory 'windows_packaged_environment.json'
        if (Test-Path -LiteralPath $EnvironmentReceiptPath) { Remove-Item -LiteralPath $EnvironmentReceiptPath -Force }
        $InventorySdk = if ($BaslerEmulator -and $DepthSdk) {'all'} elseif ($BaslerEmulator) {'basler'} elseif ($DepthSdk) {'realsense'} else {'none'}
        Invoke-Checked -Executable $ResolvedCli -Arguments @('environment-probe', '--output', $EnvironmentReceiptPath, '--sdk-inventory', $InventorySdk)
        if ($BaslerEmulator -or $DepthSdk) {
            $EnvironmentReceipt = Get-Content -LiteralPath $EnvironmentReceiptPath -Raw | ConvertFrom-Json
        }
        if ($DepthSdk -and $EnvironmentReceipt.sdk_inventory.realsense.status -ne 'enumerated') {
            throw "The packaged RealSense SDK could not initialize/enumerate devices: $($EnvironmentReceipt.sdk_inventory.realsense.error)"
        }
        if ($BaslerEmulator) {
            if ($EnvironmentReceipt.sdk_inventory.basler.status -ne 'enumerated') {
                throw "The packaged Basler SDK could not enumerate devices: $($EnvironmentReceipt.sdk_inventory.basler.error)"
            }
            $Emulators = @($EnvironmentReceipt.sdk_inventory.basler.devices | Where-Object { $_.sdk_emulator })
            if (-not $Emulators.Count) { throw 'The packaged Basler SDK did not enumerate its camera emulator' }
            $FrozenEmulatorReceipt = Join-Path $EvidenceDirectory 'windows_packaged_sdk_emulator.json'
            if (Test-Path -LiteralPath $FrozenEmulatorReceipt) { Remove-Item -LiteralPath $FrozenEmulatorReceipt -Force }
            Invoke-Checked -Executable $ResolvedCli -Arguments @('camera-soak', '--backend', 'pylon', '--source', [string]$Emulators[0].serial, '--seconds', '2', '--width', '640', '--height', '480', '--fps', '30', '--allow-simulated', '--output', $FrozenEmulatorReceipt)
        }
        $PackagedChecked = $true
    }
    $PackagedStudioChecked = $false
    if ($PackagedStudio) {
        $ResolvedStudio = (Resolve-Path -LiteralPath $PackagedStudio).Path
        $StudioReceiptPath = Join-Path $EvidenceDirectory 'windows_studio_smoke.json'
        if (Test-Path -LiteralPath $StudioReceiptPath) { Remove-Item -LiteralPath $StudioReceiptPath -Force }
        # A windowed executable has no console and must be waited on explicitly.
        $StudioProcess = Start-Process -FilePath $ResolvedStudio -ArgumentList @('--smoke-test', ('"' + $StudioReceiptPath + '"')) -PassThru
        [void]$StudioProcess.Handle
        if (-not $StudioProcess.WaitForExit(60000)) {
            Stop-Process -Id $StudioProcess.Id -Force
            $StudioProcess.Dispose()
            throw 'Packaged Studio exceeded the 60-second smoke-test timeout'
        }
        $StudioProcess.Refresh()
        $StudioExitCode = $StudioProcess.ExitCode
        $StudioProcess.Dispose()
        if ($StudioExitCode -ne 0) { throw "Packaged Studio smoke failed with exit code $StudioExitCode" }
        $StudioReceipt = Get-Content -LiteralPath $StudioReceiptPath -Raw | ConvertFrom-Json
        if ($StudioReceipt.status -ne 'passed' -or -not $StudioReceipt.frozen_executable -or $StudioReceipt.native_ui_pages_painted -lt 1) {
            throw 'Packaged Studio did not return a valid native UI verification receipt'
        }
        if ($StudioReceipt.font_verification.status -ne 'passed' -or $StudioReceipt.font_verification.ascii_glyphs_checked -ne 95 -or $StudioReceipt.font_verification.unicode_glyphs_checked -ne 14 -or @($StudioReceipt.font_verification.missing_glyphs).Count -ne 0 -or $StudioReceipt.font_verification.distinct_probe_rasters -ne 12 -or $StudioReceipt.font_verification.expected_probe_rasters -ne 12) {
            throw 'Packaged Studio text is not verified: required glyphs or distinct rendered character shapes are missing'
        }
        $FontProof = Join-Path $EvidenceDirectory $StudioReceipt.font_verification.raster_probe_png
        if (-not (Test-Path -LiteralPath $FontProof)) { throw 'Packaged Studio did not save its actual Qt glyph rendering proof' }
        $PackagedStudioChecked = $true
    }
    $PythonVersion = (& $PythonExecutable -c 'import platform; print(platform.python_version())').Trim()
    if ($LASTEXITCODE -ne 0) { throw 'Unable to read Python version' }
    $Receipt = [ordered]@{
        status = 'passed'
        verified_at_utc = [DateTime]::UtcNow.ToString('o')
        operating_system = [Environment]::OSVersion.VersionString
        python = $PythonVersion
        software_tests_executed = -not [bool]$SkipTests
        synthetic_end_to_end_session = 'passed'
        packaged_cli_smoke_test = $PackagedChecked
        packaged_face_iris_inference_test = $PackagedFaceChecked
        packaged_studio_smoke_test = $PackagedStudioChecked
        basler_sdk_emulator_test = [bool]$BaslerEmulator
        realsense_sdk_enumeration_test = [bool]$DepthSdk
        physical_hardware_tested = $false
        real_person_gaze_accuracy_established = $false
        interactive_windows_monitor_acceptance = 'Requires a real operator and calibrated display/cameras'
    }
    $ReceiptName = if ($SkipTests -and ($PackagedChecked -or $PackagedStudioChecked)) { 'windows_packaged_verification.json' } else { 'windows_verification.json' }
    $Receipt | ConvertTo-Json -Depth 8 | Set-Content -LiteralPath (Join-Path $EvidenceDirectory $ReceiptName) -Encoding UTF8
    Write-Host 'Windows software verification completed; receipts are in release_evidence.'
} finally {
    $env:QT_QPA_PLATFORM = $PriorQtPlatform
    $env:QT_API = $PriorQtApi
    $env:GAZESPACE_TEST_PYLON_EMULATOR = $PriorEmulatorOptIn
    $env:PYLON_CAMEMU = $PriorPylonEmulator
}
